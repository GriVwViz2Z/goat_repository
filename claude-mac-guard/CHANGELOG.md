# Changelog

## v0.2.0 — 2026-08-13

- 新增 Claude.app 启动门禁：每次启动前强制生成新检测快照。
- 只有出口确认、代理路径、IPv6、TLS 和 Claude.app 身份均通过才允许启动。
- Claude 已经运行时不把重新激活伪装成受保护启动。
- 节点公开信誉保持为辅助证据，不作为自动信任或启动放行规则。
- 明确保留 v0.2 边界：启动之后没有网络阻断，网络切换仍可能造成请求泄漏。

## v0.1.3 — 2026-08-13

第一个正式基线版本。

- SwiftUI 本地网络状态界面与原创 App 图标。
- 出口 IPv4 多次采样、系统代理/TUN、IPv6、TLS 与 Claude.app 签名检查。
- 将“可信出口”改为更准确的“用户已确认出口”。
- 节点公开信誉采用逐项证据，不生成虚假的绝对安全总分。
- 外部信誉查询和 Ping0、ipdata、Scamalytics 报告均在发送 IP 前取得确认。
- 明确保留 v0.1 监测边界：没有 Network Extension，不具备 fail-closed 阻断。

## Git 建立前的原型

- v0.1.2：出口确认交互原型；没有保存独立源码快照或 App 归档。
- v0.1.1：出口验证只读监测原型；本机仍留有一份可运行的 App 二进制，
  但没有对应的完整源码快照。
