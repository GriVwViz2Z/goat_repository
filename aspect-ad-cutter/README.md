# aspect-ad-cutter

macOS / Python 3 标准库 + FFmpeg 的画幅异常检测与无损广告清理工具。检测器只读；GUI 可在人工确认后导出删除广告的新 MKV，原文件保留。

## 图形界面

在 Finder 中双击 `启动广告清理.command`，会打开本机浏览器界面。也可以运行：

```sh
python3 gui.py
```

1. 点击“浏览…”选择电影，再点击“开始检测”；界面显示检测进度。
2. 查看三张预览图，点击“播放开始/结束边界”核实（FFplay，按 Q 退出）。可手工修改时间。
3. 勾选确认的广告，点击“计算已勾选区间的实际删除范围”。
4. 核对关键帧对齐后的范围、额外裁掉的时长和输出路径，勾选确认框。
5. 点击“删除已确认广告并导出 MKV”。完成后可在 Finder 中显示文件。

“载入报告”可打开之前生成的 report.json，不必重复扫描。需要保持启动器的终端窗口运行；退出程序可在该终端按 Control-C。GUI 仅监听 127.0.0.1，使用随机访问令牌，不上传影片。

### 导出方式与验证

目前提供 **无重编码、关键帧对齐** 模式。为了不留下选中广告画面，开始向前、结束向后对齐关键帧，因此可能额外删除正片。界面明确显示该差异，候选默认不勾选，确认前按钮不可用；修改候选后须重新计算计划。

导出先分段，再拼接保留片段。全部轨道使用 stream copy，尝试保留音轨、字幕、全局/轨道元数据，重映射章节时间。输出容器目前固定 MKV。不支持的轨道或保留片段参数不一致时会报错，不能保证任意片源均可直接拼接。跨切点字幕需人工复核。音频包和容器时间基舍入可能造成毫秒级时长差异。

临时文件放在输出目录旁，预留约原片两倍空间。导出后检查轨道数量、时长，并完整解码视频与音频；通过后才发布结果。现有输出文件、源文件都不会覆盖，出错自动清理临时文件。若要逐帧精确切割，需要后续增加重编码模式。

已用《压路机和小提琴》验证完整导出和解码：两段合计额外删除 8.335 秒，测试输出 45:16.902，原片两个轨道保留。另有合成测试覆盖双音轨、字幕、章节、中文/空格路径、片头/片尾删除与防覆盖。

## 命令行检测

```sh
cd aspect-ad-cutter
python3 ad_detect.py "$HOME/jellyfin/电影/压路机和小提琴/压路机和小提琴.mp4"
```

需要 PATH 中有 ffmpeg 和 ffprobe。本机验证版本 FFmpeg 9.0.1。中文和空格文件名作为独立 subprocess 参数传入，不经过 shell。

默认在当前目录 results/影片名_时间戳/ 生成：

- index.html：可直接浏览的截图预览
- report.txt、report.json：候选区间、主体画幅、参数
- previews/ad_001_start.jpg、middle.jpg、end.jpg 等
- samples.json、metadata.txt、ffmpeg.log：采样结果与诊断

`--output 路径` 可指定尚不存在的结果目录，已有目录不会覆盖。

## 检测机制

全片解码，每 0.5 秒取样，cropdetect 黑边模式每帧重置（reset=1、skip=0、round=2）。从 metadata filter 的标准输出读取 lavfi.cropdetect.w/h/x/y；时间读取实际验证过的 metadata header pts_time，不解析 cropdetect stderr 的 t/pts_time 日志。不认识的 metadata 格式会报错，不会伪装成零广告。分辨率变化时帧号可重置，因此以时间戳排序。

主体画幅取像素容差邻域中支持最多的簇，再取各维中位数。宽或高偏差须同时超过 8 像素和主体对应维度的 12%。连续异常至少 8 秒才保留，之后合并间隔不超过 2 秒的候选。黑帧无效 crop 视为未知；短暂转场过滤，片头片尾候选降低置信度。未知或正常采样不会被计入连续异常证据。对低于最低持续时间的小碎片不作合并，属于保守策略。

高置信度要求主体簇占比至少 60%、候选画幅稳定度至少 80%，且不在首尾 30 秒内。它是画幅变化证据等级，不是广告概率。

```sh
python3 ad_detect.py 'movie with spaces.mkv' --interval 1 --min-duration 10 --height-ratio 0.15 --merge-gap 2
python3 -m unittest discover -s . -v
```

`--height-ratio` 同时作用于宽、高；`--tolerance` 为像素容差；`--black-limit` 默认 0.094（归一化黑色阈值）；`--no-previews` 跳过截图。

## 已验证样片

《压路机和小提琴》时长 46:02.110，主体有效画幅 976×720（占比 98.3%）。广告期间实际解码分辨率切换为 1920×1080，不能仅凭 ffprobe 初始分辨率判断全片。

- 05:56.750–06:16.250，19.5 秒
- 28:18.750–28:36.250，17.5 秒，覆盖已知 28:30 样本

每段生成开始、中间、结束三张截图。边界采用首末异常采样点向外半个采样间隔估计，不是帧精确切点；分辨率重初始化附近也可能有采样丢失，必须播放核对。

## 检测局限

同画幅广告无法识别；艺术性变画幅、字幕触及黑边、暗场、台标、片头片尾可能误报。黑边颜色和压缩噪声可能需要调整阈值。检测器未实现 mvedges 或逐帧边界精修。检测需要解码整部片，降低采样频率不等于免除解码成本。


## 后续优化

当前版本先保存可运行的检测、人工核实与关键帧无损导出流程。后续考虑：

- 增加整片重编码的精确切割模式，避免关键帧对齐额外删除正片。
- 再评估仅切口附近重编码，其余视频直接复制；重点验证分辨率变化、编码参数与音画同步。
- 逐帧细化广告边界，并完善跨切点字幕与章节测试。

仓库仅保存源代码、说明与合成测试；电影、截图和本机检测报告不纳入版本控制。
