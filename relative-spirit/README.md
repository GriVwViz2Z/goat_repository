# relative-spirit

一个探索“数字生命感”的实验项目。

## 项目简介

relative-spirit 是一个从零构建的轻量级数字生命模拟器。

项目目标不是单纯制作一个聊天机器人，而是尝试模拟一个具有：

- 持续状态（state）
- 长期记忆（memory）
- 性格倾向（personality）
- 环境事件（event）
- 行为变化（behavior）

的简单生命系统。

通过程序规则与未来接入的大语言模型，让一个数字角色能够随着时间经历变化，并逐渐形成连续的“存在感”。

## 核心概念

### State（状态）

角色当前的内部状态：

```json
{
  "mood": 50,
  "energy": 50,
  "curiosity": 50,
  "age": 0
}
```

例如：

- mood：当前情绪
- energy：能量水平
- curiosity：探索欲
- age：存在时间

---

### Personality（性格）

角色的长期倾向：

```json
{
  "curious": 80,
  "sensitive": 60,
  "social": 30
}
```

性格不会每天改变，但会影响角色面对事件时的反应。

例如：

同样发现新事物：

高好奇角色：

> 强烈想探索

低好奇角色：

> 反应平淡

---

### Memory（记忆）

角色经历过的事件：

```json
[
  "刚刚诞生，还没有经历任何事情"
]
```

未来会扩展为：

- 重要事件
- 关系记录
- 经验总结
- 长期人格变化

## 项目理念

生命感可能并不来自一句“像人一样的话”。

更重要的是：

```
持续存在
+
过去经历
+
当前状态
+
未来倾向
```

relative-spirit 尝试探索：

> 如果一个数字系统拥有连续的状态和记忆，它是否会产生某种类似生命性的表现？
