# 抖音关注半自动清理器

这是一个 Tampermonkey 用户脚本。它会在抖音个人主页右上角显示清理面板，采集关注列表、标记疑似营销账号，并且只对你亲自勾选和二次确认的账号限速取关。

## 安装

1. 在 Chrome 安装 Tampermonkey（篡改猴）。
2. 打开 Tampermonkey 管理面板，选择“添加新脚本”。
3. 删除编辑器里的默认内容，把 `douyin-follow-cleaner.user.js` 的全部内容粘贴进去并保存。
4. 刷新 `https://www.douyin.com/user/self`。

## 使用

1. 点击个人主页上的“关注 (4051)”，保持关注列表弹层打开。
2. 点击脚本面板中的“自动滚动采集”。脚本会逐步向下滚动并保存已加载的账号。
3. 勾选“只看疑似营销”，逐个检查候选账号；分数只是关键词提示，不代表账号一定应该取关。
4. 勾选你确定要取关的账号。
5. 点击“确认并执行”，核对弹窗中的账号名后确认。每轮最多 20 个，每次操作随机间隔 9–15 秒。
6. 遇到验证码、操作频繁或按钮状态异常时，脚本会停止。此时不要继续批量操作。

## 安全设计

- 默认不取关，只采集。
- 必须逐个勾选，并在执行前再次确认。
- 每轮最多 20 个，操作带随机间隔。
- 检测到验证码、频率限制或异常按钮状态时停止。
- 进度只保存在当前浏览器的本地存储中，不会上传。
- “清空记录”只删除脚本记录，不会改变抖音关注。

## 已知限制

- 抖音更新页面结构后，脚本可能需要适配。
- 网页端只会渲染当前加载到的账号，所以采集 4000 个关注需要多轮滚动。
- “疑似营销”来自保守的关键词规则；长期停更无法仅凭关注弹层可靠判断，需要进入账号主页查看最近作品。
- 不建议提高批次上限或缩短操作间隔。
