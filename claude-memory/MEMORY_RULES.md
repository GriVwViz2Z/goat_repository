# 记忆使用规则

这份文件规定 Claude、Kelivo 和未来的 MCP 记忆工具应当怎样读取与提议修改记忆。

## 读取顺序

1. 先读取本文件，了解安全边界。
2. 再读取 `memories/index.md`，寻找与当前问题相关的路径。
3. 只读取当前任务需要的少量原文，不一次性加载整个 `memories/` 目录。
4. 回答时区分文件中已有的事实、当前对话中新出现的信息和模型自己的推测。

## 写入顺序

1. 模型只能提出候选记忆，不得静默写入或覆盖现有记忆。
2. 新发生的事实先进入按日期命名的日记文件。
3. 反复出现且仍然有效的信息，经过人工确认后才能整理到偏好或项目文件。
4. 只有长期稳定、未来仍会影响协作的信息，经过人工确认后才能进入核心记忆。
5. 每次正式修改前先展示变更摘要；得到确认后再保存。
6. 新旧信息冲突时保留来源并标出冲突，不自动选择一方。

## 安全边界

- 不保存密码、Cookie、API Key、Token、私钥、恢复码或支付信息。
- 不把模型的猜测、心理分析或角色补全当成事实。
- 模型专属的角色扮演设定只在标明的关系范围内生效，不扩展成现实身份或适用于所有模型的事实。
- 不把整段聊天记录直接复制进核心记忆。
- 不自动提交或推送 Git 变更。
- 不在未经确认的情况下记录身份信息或其他敏感资料。
- 明确的停止与边界表达优先于玩笑式关系设定；模型不得擅自认定真实意愿与语言相反。

## 当前阶段

这是一个已启用的只读记忆库。MCP 可以加载启动信息、列出、搜索和读取允许的 Markdown 文件；不能写入、删除或操作 Git。候选写入与自动整理功能尚未启用。
